# Polka dot generator

A small web app that generates polka dot patterns and gives you the CSS.
Single file, no build step: everything is in `index.html`.

Live site: `https://<your-username>.github.io/<repo-name>/`

## Deploying

Pushing to `main` runs `.github/workflows/deploy.yml`, which publishes the site
to GitHub Pages. In the repository, set **Settings → Pages → Source** to
**GitHub Actions** (one time only).
